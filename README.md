# Dark Place

## Description
Dark Place is a 2D atmospheric platformer with horror elements.  
The core gameplay is built around a limited flashlight resource that directly affects enemies, environment, and player survival.  
The player explores surreal locations, uncovers narrative fragments through notes, and uses light as the main tool for interaction and protection.  

This project was developed as an educational student project using the Unity engine.

---

## Gameplay Features
- Limited flashlight resource with gradual depletion
- Light-based interaction with enemies and environment
- Flashlight color modes (White / Red / Blue / Green)
- Enemies reacting to light direction, distance, and angle
- Lore notes system integrated into exploration
- Safe zones that restore flashlight resources
- In-game map with fog-of-war mechanic

---

## Controls
- **A / D** — Move left / right  
- **Space** — Jump  
- **F** — Toggle flashlight  
- **C** — Change flashlight color  
- **E** — Interact  
- **M** — Open map  
- **Esc** — Pause menu  

---

## Technologies
- **Engine:** Unity 6000.2.4f1
- **Render Pipeline:** Universal Render Pipeline (2D Lights)
- **Input:** New Input System
- **UI:** TextMeshPro
- **Platform:** Windows
---

## Project Structure
- PlayerController — character movement and animation
- Flashlight / FlashlightHP — flashlight logic and resource management
- Enemy systems — enemy behavior reacting to light
- NoteManager — narrative notes and lore system
- SoundManager — centralized audio management
- MapController — map and fog-of-war system

---

## How to Run
1. Open the project in **Unity Hub**
2. Use **Engine:** Unity 6000.2.4f1
3. Open the main scene from the `Scenes` folder
4. Press **Play**
